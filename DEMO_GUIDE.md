# Demo guide

1. Run the console and open `/`.
2. Enter as **MDoNER command** and open **Route intelligence**. Change the origin/destination and click **Recalculate route**. The panel confirms that it used demo corridor data.
3. Open **GIS accessibility** to inspect colored corridor and incident markers.
4. Open **AI copilot** and request emergency medicines from Guwahati to Imphal. The structured result contains route, vehicle and hub decisions.
5. In **Field reporting**, submit an online report to call the API, or enable low-network mode to queue it locally, then use the top-bar sync control.
6. Open **Accessibility** for calculated district scores.

The demo badge/disclaimer is intentional: data is seeded or simulated and does not claim live government feeds.
